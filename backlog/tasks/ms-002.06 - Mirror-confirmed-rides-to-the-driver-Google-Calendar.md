## Description

The owner chose one-way sync. All ride changes originate in the app. Personal calendar availability and edits made in Google are outside this scope.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The driver connects a chosen calendar. Accepting a web request or adding a confirmed phone or WhatsApp ride creates one event per scheduled leg. Pending and declined requests create none.
- [ ] #2 Rescheduling or changing pickup updates the existing event. Cancellation removes the applicable event. Paris time and daylight-saving transitions are covered.
- [ ] #3 Each event shows pickup, scheduled time, expected finish when known, and a link to the signed-in ride detail. Passenger numbers and private notes stay in the app.
- [ ] #4 A connection or delivery failure preserves the booking, shows the driver what is unsynced and recovers to the latest state without duplicate or stale events. Verify create, update and cancel with an authorized test calendar.
<!-- AC:END -->
