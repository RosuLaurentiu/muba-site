## Description

The current submit button opens email. Summary links can carry incomplete details, and the Maps failure text offers billing advice. Keep the useful manual address, estimate and return-trip behavior in one reservation flow.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 One primary English or French action validates pickup, destination, future Paris pickup date and time, passenger count and usable contact. A return requires a later date and time. Errors identify the affected field and work by keyboard.
- [ ] #2 The client reviews addresses, times, passenger details and an estimate. With Maps unavailable, manual addresses still work, the fare is clearly unavailable, and the request can be sent.
- [ ] #3 A successful save displays a reference and pending status. Failed saves preserve entries and allow retry. Repeated submissions do not create a second booking.
- [ ] #4 Check both languages, language switching, one-way and return trips, configured fare rules, and mobile and desktop layouts. Contact shortcuts are distinct from submitting a request.
