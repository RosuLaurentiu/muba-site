## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The driver connects a chosen calendar. Accepting a web request or adding a confirmed phone or WhatsApp ride creates one event per scheduled leg. Pending and declined requests create none.
- [x] #2 Rescheduling or changing pickup updates the existing event. Cancellation removes the applicable event. Paris time and daylight-saving transitions are covered.
- [x] #3 Each event shows pickup, scheduled time, expected finish when known, and a link to the signed-in ride detail. Passenger numbers and private notes stay in the app.
- [x] #4 A connection or delivery failure preserves the booking, shows the driver what is unsynced and recovers to the latest state without duplicate or stale events. Verify create, update and cancel with an authorized test calendar.
